# Double Pendulum with Neural Networks

Этот проект посвящён моделированию **двойного маятника** и обучению нейросетей для предсказания его динамики.  
Реализованы два подхода:
- **FCNetwork** — классическая полносвязная сеть.  
- **LNN (Lagrangian Neural Network)** — физически осмысленная модель, аппроксимирующая лагранжиан системы.  

Проект позволяет:
- генерировать данные о движении маятника,
- обучать модели,
- сравнивать их точность,
- визуализировать фазовые портреты и анимации.

## 📂 Структура проекта
├── data_generation.py   # Генерация датасета траекторий маятника  
├── models.py            # Определение архитектур (FC и LNN)  
├── train.py             # Функция обучения моделей  
├── main.py              # Интерактивное меню для экспериментов  
├── animation.py         # Анимация истинной и предсказанной траекторий  
├── dataset.npz          # Сгенерированные данные (создаются автоматически)  
├── fc_model.pt          # Сохранённая FC-модель (после обучения)  
├── lnn_model.pt         # Сохранённая LNN-модель (после обучения)  

## Установка
```bash
git clone https://github.com/your-repo/double-pendulum-nn.git
cd double-pendulum-nn
pip install -r requirements.txt
```

### Зависимости
- Python 3.9+  
- numpy  
- scipy  
- matplotlib  
- torch  

## Использование

### 1. Генерация данных
```bash
python data_generation.py
```
Создаст файл dataset.npz с траекториями маятника.  

### 2. Запуск интерактивного меню
```bash
python main.py
```
Доступные опции:  
1. Загрузить данные  
2. Обучить или загрузить модели  
3. Оценить модели через RMSE  
4. Визуализировать процесс обучения  
5. Построить фазовый портрет (True vs Predicted)  
6. Сравнить временные ряды углов и скоростей  
7. Выход  

### 3. Анимация маятника
```bash
python animation.py
```
Откроется окно с анимацией истинной (синей) и предсказанной (красной) траекторий.  

## Пример визуализации
- Сравнение фазовых портретов (PCA-проекция).  
- RMSE для FC и LNN.  
- Анимация движения маятника.  

## Идея проекта
- **FCNetwork** учится напрямую предсказывать следующее состояние.  
- **LNN** аппроксимирует лагранжиан и выводит уравнения движения, что позволяет лучше сохранять физические законы.  

## Автор
Проект создан для изучения применения нейросетей в задачах физического моделирования.
